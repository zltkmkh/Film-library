# Film-library
Курсова робота з дисципліни «Об'єктно-орієнтоване програмування» на тему «Фільмотека». Настільний застосунок на базі C# (Windows Forms, .NET 8.0) для обліку та підбору відеофайлів з власної колекції.

# Фільмотека (MovieCatalog)

[cite_start]Курсова робота з дисципліни «Об'єктно-орієнтоване програмування» студента групи ПЗПІ[cite: 5, 452].

## Про проєкт
[cite_start]Застосунок призначений для структурування особистої колекції відеофайлів та автоматизації пошуку фільмів [cite: 331-332].

## Основні функції
- [cite_start]Додавання, редагування та видалення фільмів із колекції[cite: 40].
- [cite_start]Ведення довідника режисерів[cite: 41, 87].
- [cite_start]Автоматична перевірка наявності фільму у відеотеці[cite: 332].
- [cite_start]Гнучкий підбір стрічок за кількома критеріями одночасно (жанр, рік, оцінка, режисер)[cite: 332].
- [cite_start]Автоматичне збереження та завантаження бази даних у форматі JSON[cite: 87].
